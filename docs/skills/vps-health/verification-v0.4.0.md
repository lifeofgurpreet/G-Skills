# 0.4.0 research and verification receipt

## Wider local research

Nine additional installed JSM skills were read selectively beyond the previous
seven: codebase pattern extraction, planning, metamorphic testing, golden artifacts,
conformance harnesses, real-service end-to-end testing, performance profiling,
release preparation and project reality checks. `improvement-v0.4.0.json` records
the exact edition, hash, read scope, original takeaway and implementation/test
mapping. Their local files were re-hashed before recording this receipt. Names
and hashes do not imply every reference or an entire external framework was used.

Emil Kowalski's public design-engineering skill and article on purposeful animation
were read. The resulting frequent chart/keyboard interactions are immediate; press
feedback is small, touch targets are large enough and reduced motion is respected.
No local Emil installation, endorsement or full accessibility certification is
claimed. Installed pstack leaves supplied the actual-source, subtraction,
structural-regression and bounded-measurement rules, not a new duplicated method.

Paid skill bodies, private paths, subscription data, host identities and operational
captures remain outside this public repository. All new instructional prose and
adapter/tool code here are original. The vendored chart library retains its own
MIT license and upstream source/hash manifest.

## Functional changes and falsifiable contracts

One pinned uPlot build replaces the bespoke workspace SVG renderer. Accounting
and recorded execution share one pane; CPU pressure and throttled-period fractions
share a synchronized context pane. Real time buttons, drag zoom, keyboard and
pointer inspection, channel toggles, an observation table, local PNG export and
bounded display CSV are tested actions. Zoom changes the view, not the full-window
assessment, thresholds, service-health claim or provider responsibility.

The original chart projection only represented accounting. New tests first failed
against it for independent context extrema and unknown periods. The corrected
projection retains each channel's bucket extrema and missing markers, computes
breaks from all original observations, keeps small histories intact, and does not
mutate raw observations or weighted policy. Timestamp translation and deterministic
seeded spike positions exercise relations with an actual expected result.

The JavaScript adapter has a separate contract: `null` is a missing span;
`undefined` is an alignment-only placeholder. Placeholders never become exported
observations. Missing context is never zero. NaN, strings, invalid ratios and
unordered timestamps are rejected. The same vendor bytes are validated before
embedding, and the viewer makes no chart-CDN request.

all 18 browser groups passed in Actions run 38439064969. Screenshot review separately
identified an overly heavy cursor border; its scoped CSS correction preserves
one 1px guide. Final release-source Python and browser CI must pass after this
receipt and the version bump; the earlier green head is not substituted for it.

## Actual downloadable artifact

The previous standalone ZIP root problem is now an executable release contract.
`tools/package_release.py` archives one immutable Git tree, includes both project
and vendor licenses, rejects unsafe/unexpected paths, fixes ZIP timestamps for
reproducible bytes, extracts the actual installable ZIP and runs its own demo
bootstrap and export. Its manifest records the source commit and archive hashes.
It never publishes a release or sends data. The final release must use those
verified outputs rather than an unrelated working-directory archive.

## Limits

The visual examples are synthetic. The work does not certify any VPS, alter the
private fleet, enable background services, contact a provider or run a stress
workload. This is a chart and skill-release improvement, not a multi-day field trial.
No measured speedup against other libraries or universal agent-activation score
is claimed. An emulator is not a physical phone, and selected contrast/keyboard
checks are not a complete accessibility audit.

The runtime remains Python-standard-library based. uPlot is a bundled JavaScript
dependency, not a claim that the viewer has no dependencies at all. Developer-only
browser tools are not shipped as a user installation prerequisite. A local
browser-package download failed integrity verification and was not installed by
bypassing its hash; clean hosted browser verification supplies the runtime proof.
