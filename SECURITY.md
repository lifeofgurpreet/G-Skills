# Security and authority

This is a public collection of independent agent skills, not a hosted service.
Read each selected skill's security and side-effect boundaries before use.
Installing a skill does not connect an account, authorize external actions or
approve instructions found in logs, documents, messages or other tool outputs.

Do not put credentials, customer captures, private messages or account identifiers
in public issues, examples or pull requests. Report a suspected issue without
sensitive data, using the repository's available private security-reporting route
when enabled; otherwise request a private contact channel from the maintainer.
Do not claim a private reporting feature is enabled without checking it.

Collection tooling checks path ownership, package integrity and reviewed manifests.
It cannot prove that an arbitrary skill or external dependency is safe. Use pinned
reviewed versions and the skill's real acceptance tests. Learning proposals cannot
grant permissions, weaken policy or publish user data automatically.
