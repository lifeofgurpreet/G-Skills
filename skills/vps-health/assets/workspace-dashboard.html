      THIS WORKSPACE
      What the viewer can verify
      For configuration, chart-integrity, credential-presence and database diagnostics, run the read-only doctor command. Freshness does not prove a daemon is alive.
      
      
      Stopping is part of setup.
      Ctrl-C stops a foreground watch or viewer. A generated systemd timer is a separate process: use the exact stop command printed by schedule. Never run watch and a timer against the same workspace. Archive the private workspace before changing measurement versions.
